# Portfolio site

Static portfolio ready for GitHub Pages.

## Publish

1. Create a GitHub repository (for example, `portfolio`).
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / root**.

Before publishing, edit `index.html`:

- replace `YOUR_WORK` with your name or studio;
- replace `hello@example.com` with your email;
- replace the two placeholder game titles with their actual names.
